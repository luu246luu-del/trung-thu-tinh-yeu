# 🌕 Trung Thu Tình Yêu — Thư Gửi Em 💌

Một website tương tác mang không khí Trung Thu lãng mạn, kết hợp thư tình, ánh trăng, đèn lồng, âm nhạc và hiệu ứng 3D.

## ✨ Tính năng nổi bật

- 🏮 **Cổng Trung Thu:** Hiệu ứng mở cổng với ánh trăng và đèn lồng.
- 💌 **Phong thư tình:** Tương tác để khám phá nội dung lá thư.
- 🎵 **Âm nhạc:** Nút điều khiển bật/tắt nhạc nền.
- 🌌 **Thiên hà 3D:** Không gian tương tác được xây dựng bằng Three.js và WebGL.
- 💖 **Trái tim tương tác:** Nhấn vào các trái tim để khám phá nội dung.
- 📱 **Responsive:** Giao diện thích ứng với máy tính và điện thoại.
- ✨ **Hiệu ứng động:** Chuyển cảnh, ánh sáng, chuyển động và hiệu ứng khi chạm.

## 🛠️ Công nghệ sử dụng

- HTML5
- CSS3
- JavaScript
- Three.js / WebGL
- Google Fonts

## 🚀 Hướng dẫn chạy trên máy tính

**Bước 1:** Tải repository về máy.

```bash
git clone https://github.com/luu246luu-del/trung-thu-tinh-yeu.git
```

**Bước 2:** Mở thư mục dự án bằng Visual Studio Code.

**Bước 3:** Cài tiện ích Live Server trong VS Code.

**Bước 4:** Nhấp chuột phải vào `index.html`, chọn **Open with Live Server**.

**Bước 5:** Trải nghiệm website trên trình duyệt.

Dự án không yêu cầu cài Python hoặc Node.js để chạy giao diện hiện tại.

## 🌐 Triển khai GitHub Pages

1. Mở repository trên GitHub.
2. Chọn **Settings → Pages**.
3. Tại **Build and deployment**, chọn **Deploy from a branch**.
4. Chọn nhánh `main` và thư mục `/ (root)`.
5. Nhấn **Save** và chờ GitHub Pages triển khai.

## 📝 Lưu ý

- Không thay đổi tên hoặc đường dẫn tài nguyên trong thư mục `images/` và `nhac/`.
